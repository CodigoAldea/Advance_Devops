# Docker & Kubernetes (Minikube) Test 

Total Questions: 10
Total Marks:** 50 (5 Marks Each)

# Submission Requirements

    Students should submit:

    1. Screenshots of every command executed.
    2. All Dockerfiles.
    3. All Kubernetes YAML files.
    4. Output of:

    ```bash
    docker ps
    docker images
    kubectl get pods
    kubectl get deployments
    kubectl get services
    kubectl get nodes
    ```
    5. A ZIP folder containing:

    * Dockerfiles
    * YAML files
    * Screenshots
    * Python/Django source code (where applicable)


Question 1 Marks: 5

Install Docker on your system and verify that it has been installed successfully.

Requirements:

* Display the Docker version.
* Display Docker system information.
* Take screenshots of the commands executed.

---

Question 2 Marks: 5

Run an Nginx container using Docker.

Requirements:

* Name the container `my-nginx`
* Map port `8080` on the host to port `80` inside the container.
* Verify the website is accessible in the browser.
* Display the list of running containers.

---

Question 3 Marks: 5

Create a Docker image for a simple Python application.

Application:

```python
print("Welcome to Docker")
```

**Requirements:**

* Write a Dockerfile.
* Build the image.
* Run the container.
* Show the output.

Question 4 Marks: 5

Create a Docker volume and attach it to an Ubuntu container.

Requirements:

* Create a volume named `student-data`
* Mount it inside the container at `/data`
* Create a text file inside `/data`
* Stop and restart the container.
* Verify that the file still exists.
